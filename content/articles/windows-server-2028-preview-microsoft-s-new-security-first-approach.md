## Microsoft's Security-First Approach for Windows Server 2028

Microsoft has unveiled a significant shift in its approach to server security with the Windows Server 2028 Public Preview. The update introduces a new security-by-default stance, aiming to address a longstanding concern for system administrators.

## Hardened Server Core: A New Security Baseline

The key feature of this update is Hardened Server Core, a set of security settings that align with strengthened U.S. Department of Defense guidelines, including the DISA Security Technical Implementation Guide recommendations. This approach ensures that the secure configuration is the starting state, eliminating the need for administrators to manually harden servers after deployment.

## Technical Improvements and User Experience

The update also brings technical improvements, such as eliminating NVMe translation through a SCSI stack, which enhances speeds and reduces overhead. However, it's important to note that these changes are only available for Server Core installations, and Windows Server Desktop Experience installs do not include the new security stance.

## User Feedback and Future Updates

Microsoft encourages users to test the build and provide feedback on which settings may interfere with applications. The company also plans to introduce hardware-supported security mechanisms, like Secure Boot and DMA requirements, in later preview builds. This iterative approach ensures that the final release will be thoroughly tested and optimized for security and performance.

## What the Evidence Shows

Microsoft's Windows Server 2028 Public Preview represents a significant step towards a more secure server environment. By making Hardened Server Core the default, the company is addressing a critical security gap, ensuring that servers are protected from the moment they are deployed. This proactive approach aligns with industry best practices and is a welcome development for system administrators and security-conscious users.
